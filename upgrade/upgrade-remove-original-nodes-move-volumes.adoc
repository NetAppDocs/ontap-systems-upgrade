= Remove the original nodes from the cluster
:icons: font
:imagesdir: ../media/

[.lead]
After moving the volumes from the original to the new nodes and moving or deleting data LIFs, you remove the original nodes from the cluster. When you remove a node, the node's configuration is erased and all disks are initialized.

.Steps
. [[disable-ha]]Disable high-availability (HA) configuration on the original nodes:
+
[source,cli]
----
storage failover modify -node <original_node_name> -enabled false
----

include::https://raw.githubusercontent.com/NetAppDocs/ontap/main/_include/remove-nodes-from-cluster.adoc[]

[start=11]
. Repeat Steps <<disable-ha,1>> to <<return-admin,10>> to remove the failover partner from the cluster.

. If the cluster has only two nodes remaining, configure high availability for the two-node cluster:
+
[source,cli]
----
cluster ha modify -configured true
----
